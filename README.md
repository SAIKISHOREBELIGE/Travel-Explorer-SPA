# Travel Explorer SPA

A simple and responsive Single Page Application (SPA) built using HTML and CSS. This project showcases a travel-themed landing page with a clean layout and responsive design.

## Features

* Responsive design
* Travel-themed user interface
* Clean and modern layout
* HTML5 semantic structure
* CSS styling

## Technologies Used

* HTML5
* CSS3
